# 每日三梯队选股

一个独立运行的沪深 A 股筛选与历史记录网站。页面只保留两个功能：查看当天三梯队选股，以及通过日历回看每天的选股和至今表现。

## 当前选股规则

三梯队都必须满足：按原指标公式计算，最近 4 个实际交易日内仍显示“可能见底”，并排除 ST、*ST。窗口包含当前交易日；停牌造成的缺失 K 线不会延长窗口。

- 第一梯队：当天之前连续 3 个交易日，`|龙线 - 虎线|` 每一天都不大于 `0.5`。
- 第二梯队：当前股价不高于黄线。
- 第三梯队：不满足前两项附加条件，但近 4 个交易日出现“可能见底”。
- 去重：优先级为第一梯队、第二梯队、第三梯队，同一股票只出现一次。

“前三个交易日”不包含当天正在变化的 K 线，因此盘中不会因当天龙虎线波动反复改变第一梯队的三日判断。黄线沿用原指标中的 `XMA(XMA(H,25),25)`。

“可能见底”按原图公式逐次识别：当天仍在形成的 ZIG 低点不提前入选；至少经过一个后续交易日、图中文字标记已经出现，且当日振幅与 CCI14 条件同时满足后才计入。达到 16% 反弹后波谷得到确认；确认前的临时文字仍可能因后续新低而重绘消失，届时会自动移出梯队并保留历史记录。

当日入选卡片还会显示极简公司简介、所属行业板块和最多 3 个主要概念，资料来自公开的东方财富公司概况与行情字段；资料接口临时不可用时不影响数值筛选。

卡片财务区显示最新已披露定期报告的营业总收入同比、归母净利润同比、扣非归母净利润同比，以及经营现金流净额 / 归母净利润（倍）。三个同比均为年初至报告期末累计值与上年同期比较，四项来自同一份财报，卡片注明报告期及数据来源。现金利润比用于辅助观察利润的现金支撑，不能单独判断买卖；归母净利润非正时显示“不适用”，缺失数据为“暂无”。

财报使用东方财富 `RPT_F10_FINANCE_MAINFINADATA` 数据，缓存独立于公司简介，每 12 小时检查更新；失败时保留并标明旧缓存、两小时后再试，不占用每五分钟行情刷新中的重复下载时间。这些财务数据只用于当下卡片展示，不参与入选或历史胜率计算；数据源对旧报表的后续修订不等于历史当时可得数据。

今日选股支持按见底后价格绝对差额、今日涨跌幅和四项财务指标升序或降序排列。三个梯队各自排序，默认差额从小到大，暂无或不适用数据始终排末；浏览器记住排序选择，行情刷新后继续沿用。排序仅改变显示顺序，不改变入选或统计。

## 历史日历与统计

盘中首次入选、移除和收盘状态写入 `results/history.json`。同一股票在不同日期再次入选，按独立记录保留。

- 至今收益：最新可得价格相对该日首次有效入选记录价格的涨跌幅；只在收盘首次发现的股票以当时收盘价记录。
- 成功：已经经过至少一个后续交易日，且至今收益大于 0。
- 当月胜率：按入选日归入当前日历月份，成功记录数除以该月已产生后续行情的记录数；切换日历月份时同步重算。
- 当月入选平均至今收益：仅取所选日历月份入选且已有后续有效行情的记录，按至今收益等权计算；切换月份同步重算，不使用所有月份的累计平均。同股跨日入选按独立记录计算，缺失收益不计入，有效 0% 计入。
- 当日刚入选的记录不提前计为成功或失败。
- 经核查确认信号超期或指标基准失效的误选，保留原记录并移入“历史纠错”，不计收益和胜率。资料不足的旧记录标为未充分核验，不伪造当时的行情与信号。

新规则从首次正式发布日起独立统计，不混入旧策略历史。

## 自动运行

GitHub Actions 独立运行，不依赖个人电脑，也不会消耗 Codex 或 OpenAI 额度。

- `Intraday market refresh`：中国时间交易日盘中约每 5 分钟更新最新价格、涨跌和三梯队名单。
- `Daily close screening`：交易日收盘数据稳定后完成全市场筛选，写入当天历史记录并发布网页。
- 北京时间 09:00 增加上一完整交易日补跑检查；只在收盘基准缺失时运行，不使用尚未收盘的当日数据。
- 中国时间周末不执行计划任务；休市日由交易日检查再次拦截。

日线先检查通达信接口能否实际读取并解码，再自动使用腾讯公开 HTTPS 前复权日线备用接口。完整性检查失败时保留上一份收盘数据，不覆盖为成功结果。盘中种子只能用于同一交易日或相邻的真实交易日；基准过期时网页显示“选股暂停”，仍可刷新可信报价和历史收益，不把暂停误记成信号消失。免费行情与 GitHub 排队均不保证严格五分钟到账。

## 主要文件

- `config.json`：近四日窗口和龙虎差阈值。
- `simple_strategy.py`：三梯队唯一生产规则。
- `selection_history.py`：每日名单、至今收益和成功率记录。
- `simple_report_ui.py`：极简网页渲染。
- `results/latest.html`：最近生成的完整页面。
- `results/live.json`：盘中实时页面数据。
- `results/history.json`：新规则启用后的每日历史账本。
- `cloud_snapshot.json`：盘中数值重算种子。

## 手工运行

在 PowerShell 中运行：

```powershell
.\run_daily.ps1
```

建议在交易日收盘数据稳定后执行。盘中信号可能变化，日历保留实际观察记录；不能将事后重算的历史信号补记为当时已推荐。

历史核查使用 `python audit_signal_history.py`，默认只读。明确确认后才加 `--apply`；应用前自动备份原始历史和审计摘要。指定已证实的陈旧基准区间需同时提供 `--stale-from`、`--stale-through`、`--stale-base`，不能凭推测填入。

## 数据边界

- 覆盖沪深 A 股，暂不含北交所。
- 免费公开行情适合个人研究与展示，商业用途应更换有授权的数据源。
- 成功率和收益仅是按上述口径生成的历史记录，未计交易费用、滑点和涨跌停无法成交。
- 本项目是条件筛选工具，不构成投资建议，也不承诺收益。
