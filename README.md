# 阿里股神每日选股

卢氏龙虎趋势池包含主选区和次选区。次选区必须同时满足近期“龙腾跃虎”和上穿日前 2 日至上穿后 10 个交易日内的黄柱，并在“可能见底”或最近 42 个交易日涨停中至少再满足一项；满足全部条件时进入主选区。

这是一个可每日运行、可把结果网页直接转发给别人的沪深 A 股筛选器。当前规则：

- 最近 5 个交易日出现“可能见底”；
- 最近 11 个交易日出现“龙腾跃虎”（龙线从下向上穿过虎线），且当前龙线仍在虎线上方；该窗口用于等待上穿后的低位黄柱确认；
- 最近 42 个交易日至少一次收盘涨停；
- 龙腾跃虎发生日前 2 个、当天或后 10 个交易日内，K 线实体有一部分位于龙线下方，即龙线高于开盘价与收盘价中的较低者，至少出现 1 根黄柱；
- ST、*ST 股票不进入主选区、次选区或观察区。

## 卢氏龙虎趋势池

每天所有严格入选股票都会进入“卢氏龙虎趋势池”：

- 加入价采用入选日收盘价；
- 页面约每 5 分钟更新跟踪股票的最新价、实时收益和趋势状态；未触发结束时统一显示“上升趋势中”；
- 盘中主选区和次选区按最新开高低收重算；达到趋势结束条件时立即从实时区域移出，并显示“趋势结束 · 待收盘结算”；
- 成功率、实现收益、正式加入、升级和移出事件只在交易日收盘完整扫描后结算；
- 入选后龙线连续两个交易日下行、且龙虎差连续两个交易日收窄时保留内部转弱观察，但不直接判定趋势结束；
- 曾达到 5% 收盘浮盈后，实时价较持有期最高收盘价回撤 20% 时触发趋势结束；未触发时在完成 60 个后续交易日后结束跟踪；
- 已结束的股票以后再次出现新的有效信号时，可以按新加入日和新加入价重新进入相应区域；同一结束日不会用旧信号立即重新加入；
- 次选区条件补齐升级主选区时不视为卖出，保留原加入日、加入价和完整持有期；
- 当前成功率统计所有在池浮盈样本与已移出盈利样本；已完成胜率只统计已移出样本；
- 收益统计按每只股票等权计算，不含手续费、滑点和实际仓位。

## 文件

- `tdx_live_formula.txt`：可复制进通达信的条件选股公式；
- `config.json`：筛选窗口与所需黄柱根数；
- `results/latest.html`：最新可转发网页；
- `results/选股结果_日期.csv`：可继续筛选的表格；
- `strategy/卢氏龙虎趋势池_最新.csv`：当前跟踪和历史移出清单；
- `strategy/state.json`：持续跟踪状态，请勿手工删除或修改；
- `results/rolling_validation.json`：逐日无未来数据的历史滚动验证结果；
- `rolling_validation.py`：以“龙腾跃虎 + 黄柱”为基础启动信号，统计涨势持续时间并比较趋势结束规则；
- `screener.py`：每日扫描程序。

## 手工运行

双击或在 PowerShell 运行：

```powershell
.\run_daily.ps1
```

首次安装环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

建议收盘数据稳定后运行，例如交易日 15:20 以后。程序会拒绝用当天 15:15 前的盘中日线更新日报和策略状态；节假日运行会得到最近一个交易日的结果。

## 全云端运行

仓库包含三个 GitHub Actions 工作流，不依赖个人电脑，也不调用 Codex 或 OpenAI：

- `Intraday market refresh`：交易时段约每 5 分钟读取全市场最新开高低收，以数值公式重算主选区、次选区和实时趋势状态；盘中只发布临时判断，不修改成功率、实现收益或正式进出状态。
- `Daily close screening`：交易日 15:40 和 16:40 由外部定时器触发，17:40 由 GitHub 自带计划任务兜底；只有交易日向前推进时才保存策略状态并发布新日报。
- `Weekly rolling validation`：每周五 19:30 逐日重放“龙腾跃虎 + 黄柱”基础信号，统计到顶时长、行情持续时间并比较退出规则；周末不运行，不参与每 5 分钟盘中刷新。

网页由 GitHub Pages Actions 直接部署。`cloud_snapshot.json` 保存收盘后生成的压缩数值种子，盘中无需重复下载 180 日历史数据，也不依赖图片形态识别。

## 数据范围与限制

- 当前自动扫描覆盖沪深 A 股；北交所没有纳入首版，因为所用通达信公开行情接口不能稳定取得北交所完整证券列表。
- ST、*ST 股票按当前证券名称排除；名称变为 ST 后会从趋势池移出。
- 免费公开行情适合个人研究和小范围分享；若用于商业化公开服务，应换成有授权的行情源，并遵守数据许可。
- 这是技术条件筛选，不是收益承诺，也不构成投资建议。上线推送前应做样本外回测，并计入停牌、涨跌停无法成交、滑点和手续费。
