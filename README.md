# 每日两梯队选股

一个独立运行的沪深 A 股筛选与历史记录网站。页面只保留两个功能：查看当天两梯队选股，以及通过日历回看每天的选股和至今表现。

## 当前选股规则

两梯队都必须满足：最近 2 个交易日内，通达信当前完整历史图仍显示“可能见底”，并排除 ST、*ST。

- 第一梯队：当天之前连续 3 个交易日，`|龙线 - 虎线|` 每一天都不大于 `0.5`。
- 第二梯队：当前股价同时不高于龙线、虎线和黄线。
- 去重：同时符合两项时只进入第一梯队。

“前三个交易日”不包含当天正在变化的 K 线，因此盘中不会因当天龙虎线波动反复改变第一梯队的三日判断。黄线沿用原指标中的高价双重 25 日平滑线。

“可能见底”按原图公式识别：收盘价 16% ZIG 波谷已经得到后续反弹确认、当日振幅满足条件，且 CCI14 小于 -110。`TROUGHBARS` 属于未来函数，当前尚未确认的下跌低点不会提前算作信号；完整历史图重算后，历史标记仍可能变化。

当日入选卡片还会显示极简公司简介、所属行业板块和最多 3 个主要概念，资料来自公开的东方财富公司概况与行情字段；资料接口临时不可用时不影响数值筛选。

## 历史日历与统计

每日收盘后的两梯队名单写入 `results/history.json`。同一股票在不同日期再次入选，按独立记录保留。

- 至今收益：最新可得价格相对入选日收盘价的涨跌幅。
- 成功：已经经过至少一个后续交易日，且至今收益大于 0。
- 总成功率：成功记录数除以已产生后续行情的记录数。
- 当日刚入选的记录不提前计为成功或失败。

新规则从首次正式发布日起独立统计，不混入旧策略历史。

## 自动运行

GitHub Actions 独立运行，不依赖个人电脑，也不会消耗 Codex 或 OpenAI 额度。

- `Intraday market refresh`：中国时间交易日盘中约每 5 分钟更新最新价格、涨跌和两梯队名单。
- `Daily close screening`：交易日收盘数据稳定后完成全市场筛选，写入当天历史记录并发布网页。
- 中国时间周末不执行计划任务；休市日由交易日检查再次拦截。

固定网址：<https://lupufan0519-design.github.io/ali-stock-daily-picks/>

## 主要文件

- `config.json`：近两日窗口和龙虎差阈值。
- `simple_strategy.py`：两梯队唯一生产规则。
- `selection_history.py`：每日名单、至今收益和成功率记录。
- `simple_report_ui.py`：极简网页渲染。
- `results/latest.html`：最近生成的完整页面。
- `results/live.json`：盘中实时页面数据。
- `results/history.json`：新规则启用后的每日历史账本。
- `cloud_snapshot.json`：盘中数值重算种子。

## 手工运行

在 PowerShell 中运行：

```powershell
.\run_daily.ps1
```

建议在交易日收盘数据稳定后执行。正式历史名单以完整收盘数据记录；盘中列表属于实时预览。

## 数据边界

- 覆盖沪深 A 股，暂不含北交所。
- 免费公开行情适合个人研究与展示，商业用途应更换有授权的数据源。
- 成功率和收益仅是按上述口径生成的历史记录，未计交易费用、滑点和涨跌停无法成交。
- 本项目是条件筛选工具，不构成投资建议，也不承诺收益。
